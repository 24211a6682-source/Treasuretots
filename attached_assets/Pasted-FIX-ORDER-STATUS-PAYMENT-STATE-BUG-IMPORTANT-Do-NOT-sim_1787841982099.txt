FIX ORDER STATUS / PAYMENT STATE BUG

IMPORTANT:
Do NOT simply change the displayed "Received" text. Trace the existing order and payment flow and fix the underlying state logic.

PROBLEM:

I tested the website by:

1. Selecting a product.
2. Going through checkout.
3. Proceeding to the payment stage.
4. NOT completing the payment.
5. Cancelling/exiting the payment process.
6. I did NOT select Cash on Delivery.

However, the order still appears in the order history/admin order page as:

Order Status: Received
Payment Status: Pending

This is incorrect.

An unpaid online-payment order must NOT automatically become "Received".

==================================================
EXPECTED ORDER LOGIC
==================================================

There are two separate concepts:

1. PAYMENT STATUS
2. ORDER STATUS

Do NOT merge these concepts.

For online payment:

Before successful payment:

Payment Status:
Pending

Order Status:
Payment Pending / Awaiting Payment

After successful verified payment:

Payment Status:
Paid / Successful

Order Status:
Received / Confirmed

If payment is cancelled:

Payment Status:
Cancelled / Unpaid

Order Status:
Cancelled

If payment fails:

Payment Status:
Failed

Order Status:
Payment Failed / Cancelled

Choose the existing status naming convention already used by the application rather than unnecessarily introducing many new status values.

==================================================
CASH ON DELIVERY
==================================================

COD is different.

If the customer explicitly selects Cash on Delivery:

Payment Status:
Pending / COD

Order Status:
Received / Confirmed

because COD is a valid placed order even though payment has not happened yet.

IMPORTANT:

Only an explicitly selected COD order may be considered a valid received order without online payment.

An online-payment order must NOT become Received merely because the checkout/order record was created.
