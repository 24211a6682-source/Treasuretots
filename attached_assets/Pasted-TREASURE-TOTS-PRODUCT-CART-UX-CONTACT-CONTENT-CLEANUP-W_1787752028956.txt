PART 1 — PRODUCT DETAIL CART / QUANTITY CONTROL
============================================================

CURRENT PROBLEM:

The product detail page currently has a separate quantity selector such as:

[ Buy 1 Now ]

[ Add to Cart ]

REMOVE THE SEPARATE QUANTITY SELECTOR COMPLETELY.

There must be only ONE quantity/cart control.

============================================================
INITIAL STATE — PRODUCT NOT IN CART
============================================================

Show:

[              Add to Cart              ]

There must be NO separate:

[ − 1 + ]

quantity selector anywhere above or below it.

Keep Buy Now as a separate button below the cart control:

[              Buy 1 Now              ]

============================================================
AFTER CLICKING "ADD TO CART"
============================================================

When the user clicks Add to Cart:

- Add the product to the existing cart with quantity = 1.
- The Add to Cart button itself must transform into the unified quantity/cart control.

Display:

[       Remove       1             +     ]

Structure:

LEFT   = Remove
CENTER = 1
RIGHT  = +

The quantity starts at 1.

============================================================
WHEN USER CLICKS "+"
============================================================

Increase the actual cart quantity.

Example:

1 → 2

Display:

[          −          2          +       ]

For quantity >= 2:

LEFT   = −
CENTER = current quantity
RIGHT  = +

Examples:

[          −          2          +       ]

[          −          3          +       ]

[          −          4          +       ]

etc.

============================================================
WHEN USER CLICKS "−"
============================================================

If quantity > 1:

Decrease the actual cart quantity by 1.

Example:

2 → 1

When quantity becomes 1, change the left control back to:

Remove

So:

[          −          2          +       ]

becomes:

[       Remove       1             +     ]

============================================================
WHEN USER CLICKS "REMOVE"
============================================================

Remove the product completely from the existing cart.

Then reset the UI to:

[              Add to Cart              ]

The quantity should disappear.

The actual cart state and cart badge/count must also update.

============================================================

Quantity 1:

etc.
